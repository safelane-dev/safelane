---
title: Roadmap
description: Current work and later options for SafeLane.
---

## Current

- Register an existing Argo canary.
- Check the exact candidate, artifact, baseline, CI result, and target.
- Recommend **proceed** or **wait**.
- Ask for one exact approval.
- Monitor Argo to completion or a safe stop.
- Store history and proof.

## Next

- Store small, verified Application and Environment facts.
- Show the same release through other chat interfaces.
- Recover an active release without chat history.
- Test separate release and read-only watch modes.

## Not planned

- reusable approval;
- chat-based mutation without the release boundary;
- numeric risk formulas;
- general security scanning;
- non-Argo rollout engines;
- a dashboard;
- multi-cluster federation.

Roadmap items do not have committed dates.
